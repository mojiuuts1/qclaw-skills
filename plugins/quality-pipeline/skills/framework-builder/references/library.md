# 常用框架参考库

> 按领域分类的常用框架清单。**注意**：此清单并非详尽，只是起点——在具体场景中还需要搜索该领域的最新框架。
>
> 每条框架标注了来源，经过事实核查验证。⚡标记表示来源有争议或信息需要进一步确认。

---

## 投资 / 商业

| 框架 | 一句话描述 | 来源 |
|------|-----------|------|
| **SWOT 分析** | 从 Strengths（优势）、Weaknesses（劣势）、Opportunities（机会）、Threats（威胁）四个维度分析内外部环境 | Albert Humphrey, 斯坦福研究院, 1960s |
| **波特五力** | 分析行业竞争强度的五个力量：新进入者威胁、替代品威胁、供应商议价能力、买方议价能力、现有竞争者 | Michael Porter, HBR, 1979 |
| **杜邦分析** | 将 ROE（净资产收益率）分解为利润率、资产周转率和财务杠杆三要素 | DuPont Corporation, 1910s |
| **DCF（现金流折现法）** | 将未来现金流折现到现值，评估投资/企业价值 | Irving Fisher 理论基础, 1930 |
| **安索夫矩阵** | 按市场（现有/新）×产品（现有/新）生成四种增长策略 | Igor Ansoff, 1957 |
| **BCG 矩阵** | 按市场增长率×相对市场份额将业务分为明星/金牛/问题/瘦狗 | Bruce Henderson, BCG, 1970 |

## 表达 / 写作

| 框架 | 一句话描述 | 来源 |
|------|-----------|------|
| **金字塔原理** | 结论先行，上层思想是下层思想的概括，同层 MECE | Barbara Minto, 1987 |
| **SCQA** | 情境（Situation）→ 冲突（Complication）→ 问题（Question）→ 答案（Answer） | Barbara Minto, 金字塔原理 |
| **PREP** | 观点（Point）→ 理由（Reason）→ 例证（Example）→ 重申观点（Point） | ⚡ 来源争议：Brian Tracy / Toastmasters / 大石哲之 |
| **STAR** | 情境（Situation）→ 任务（Task）→ 行动（Action）→ 结果（Result），常用于面试和案例 | 企业招聘领域通用 |

## 产品 / 设计

| 框架 | 一句话描述 | 来源 |
|------|-----------|------|
| **KANO 模型** | 将产品功能分为基本型、期望型、兴奋型、无差异型、反向型五类 | 狩野纪昭（Noriaki Kano）, 1984 |
| **HEART** | 五个 UX 度量维度：Happiness（幸福感）、Engagement（参与度）、Adoption（采纳）、Retention（留存）、Task Success（任务成功） | Kerry Rodden 等, Google, 2010 |
| **RICE** | Reach（覆盖）× Impact（影响）× Confidence（信心）/ Effort（投入）的产品优先级评分模型 | Sean McBride, Intercom |
| **AARRR（海盗指标）** | Acquisition（获取）→ Activation（激活）→ Retention（留存）→ Revenue（收入）→ Referral（推荐） | Dave McClure, 500 Startups, 2007 |
| **JTBD（Jobs to Be Done）** | 用户"雇佣"产品来完成什么任务？聚焦需求本质而非功能 | Clayton Christensen, HBR, 2005 |
| **双向对比表（Eisenhower Matrix）** | 按紧急×重要四象限排定任务优先级 | 源于 Dwight D. Eisenhower |

## 问题解决 / 思维

| 框架 | 一句话描述 | 来源 |
|------|-----------|------|
| **MECE** | 要素之间互不重叠、合起来完全穷尽——分类和问题拆解的底层原则 | Barbara Minto, 金字塔原理（溯源至亚里士多德） |
| **5W2H** | 谁（Who）、什么（What）、何时（When）、哪里（Where）、为什么（Why）、怎么做（How）、多少成本（How much） | 源于新闻学 5W + 精益管理补充 |
| **第一性原理** | 回归问题最基本的原理/事实，从底层重新推导，而非类比 | 亚里士多德 → Elon Musk 推广 |
| **思维导图** | 以中心主题辐射分支的放射性思维可视化工具 | Tony Buzan, 1970s |
| **5 Whys** | 连续追问五次"为什么"以找到问题根因 | Sakichi Toyoda, 丰田生产系统 |

## 学习 / 知识管理

| 框架 | 一句话描述 | 来源 |
|------|-----------|------|
| **费曼技巧** | 试图用简单的语言向别人解释一个概念——讲不通的地方就是自己没真懂 | Richard Feynman（非正式提出，以他命名） |
| **刻意练习** | 有明确目标、即时反馈、处于学习区边缘的重复训练 | Anders Ericsson, 1993 |
| **艾宾浩斯遗忘曲线** | 记忆随时间呈指数衰减，通过间隔重复对抗遗忘 | Hermann Ebbinghaus, 1885 |
